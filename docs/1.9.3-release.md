# MundusMaker 1.9.3

A polish release from the pre-release audit. All 1.9.2 features remain
included, and no map changes: the map generators were not touched, and every
map draws as it did.

## Fixes

- **No more stray "null".** Six places showed the word "null": every map and
  the Handouts page in player preview, an entry with exactly one unlinked
  mention, Vampire's Spend XP, the Call of Cthulhu development phase, and the
  second-folder backup card in Settings.
- **The New entry box has room for a name.** It gets a row of its own in the
  sidebar; beside the category picker it had shrunk to a sliver.
- **Names sort the way you read them**: Session 2 comes before Session 10 in
  the sidebar, pickers, categories, the world PDF and the player wiki.
- **World PDFs keep headings with what follows.** Category headings, headings
  inside entries, GM SECRET labels and timeline age headings no longer sit
  alone at the foot of a page, and an entry that is only a map keeps its map
  on the same page as its name.

## Keyboard and screen readers

- The **GM view / Player preview** switch in the top bar can be reached with
  Tab and flipped with Space, and screen readers announce it as a switch.
- Map editor color swatches say their color ("Color: green") and which one is
  picked.

## Guides

- README-FIRST.html covers 1.9.1 to 1.9.3, and the guides point at ⏻ Quit at
  the top right of the app.
- DATA-SAFETY.md is written for GMs, with a short note for developers.
- compose.yaml tags the Docker image with this version, and a test keeps the
  two in step.
- About calls the tensor-street maps "Modern city maps", as the map menu does.

## Verification

- `npm test` (196 tests, including the new compose tag check), the offline
  player wiki check and the phone runtime check pass.
- Every screen of the sample world, every entry, map and handout, opened in GM
  view and in player preview (198 visits): no errors and no stray text. At
  360 px nothing scrolls sideways.
- World PDFs compared with the 1.9.2 code across 32 export variants (both
  editions, with and without maps, three sheet layouts, four category mixes):
  pages ending on a lone heading or GM SECRET label went from 36 to 0, with
  the same page counts except one variant that gained a page. For entries
  that are only a map, the heading and the map landed on different pages 84
  times out of 108 before and never after.
- The map hash gate shows only the same 8 browser differences as 1.9.2
  (anti-aliased edge pixels in Edge 156, and now Chrome 156 too); no map code
  changed, so the baselines were not re-recorded.
- The release uses Node v24.20.0, the same runtime as 1.9.2.
- The player PDF still holds none of the 29 secrets the GM PDF holds, in both
  the screen and compact sheet layouts.
- The archive: its checksum verifies; nothing private or contributor-only is
  inside; its file list matches 1.9.2's exactly; every version stamp
  (package.json, the Mac bundle, the runtime manifest, compose.yaml) says
  1.9.3; launchers and runtimes keep their Unix permissions.
- From the archive itself: the bundled Windows runtime serves 1.9.3 on a fresh
  folder (sample world seeded) and stops cleanly on Quit. Extracted beside a
  used 1.9.2, it copied that install's world and entry on first start, skipped
  the untouched sample, and left the 1.9.2 folder byte-identical.

Not checked: native Mac and Linux launches, a Docker image build, and the
Android app, which stays at 1.9.2 until it is rebuilt.

One **MundusMaker-1.9.3.zip** still covers Windows, Apple silicon/Intel Macs
and Linux x64/ARM64.
