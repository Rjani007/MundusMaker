# MundusMaker 1.10.0

The first public release, published on GitHub as
[v1.10.0](https://github.com/Rjani007/MundusMaker/releases/tag/v1.10.0).
The website's Get MundusMaker button opens the latest release.

## Since 1.9.3

- A first start makes one empty world, My World. The sample world is one
  click away: **Add the sample world** on the dashboard (`sample/` still
  ships for it).
- Character files: a sheet leaves a world as a `.character.json` file and
  comes back in. Elysium reads and writes the same files.
- The Import page reads filled-in V5 character sheet PDFs: Renegade's
  official sheet and Progeny's.
- A player wiki can go online on the MundusMaker website.
- Check for updates works: package.json names `Rjani007/MundusMaker`.
- README, Help, the welcome tour and README-FIRST.html are shorter and in
  plain words.
- Node v24.22.2 (1.9.3 had v24.20.0; v24.22.1 was a security release).

## Verification

- `npm test` (211) and `npm run test:package` (14) pass.
- Check for updates, live against GitHub before the release: "No release has
  been published yet."
- The archive, MundusMaker-1.10.0.zip (205.8 MB, 453 entries, sha256
  `6081427ddec85ea1d1de15c29ae7c1502461d595f25290508f1bd66ddd4e51ed`): both
  checksum files match. At any depth there is no AGENTS.md, CLAUDE.md,
  `.claude`, session_handoff, `docs`, `tests`, `site`, `supabase`, `.github`,
  serve-site.js, `data` or `mobile`, and no PDF at all. Launchers and the Unix
  runtimes are executable. package.json, the Mac bundle, the runtime manifest
  and compose.yaml say 1.10.0, and the manifest says Node v24.22.2. The
  packaged README has no `docs/` links and links the latest release. help.js,
  onboarding.js and README-FIRST.html are byte-identical to the repository.
- From the archive, on the bundled Windows runtime: a named empty data folder,
  and the default data folder of a copy unzipped on its own, both start with
  one empty world, My World, show no upgrade notice and stop cleanly on Quit.
- Upgrade: unzipped beside a used 1.9.3 (its seeded sample plus a world of its
  own), 1.10.0 copied only that world and its entry, added no sample and no
  My World, showed the upgrade notice and left the 1.9.3 folder
  byte-identical (456 files).
- In the app: Settings shows 1.10.0 and the GitHub update text, and the
