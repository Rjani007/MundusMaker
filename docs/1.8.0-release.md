# MundusMaker 1.8.0

Maps and handouts are the focus of this release. The app remains free, fully
local, and usable without accounts, cloud services or AI generation.

## Maps

- **Worlds:** continental, archipelago, inland-sea and highland compositions;
  mountain chains, drainage basins and lakes; prevailing moisture and climate;
  terrain-shaped national boundaries; engraved relief, forests and measured
  labels.
- **Regions:** higher-precision saved world crops preserve coastlines and the
  selected territory outline. Existing capitals and settlements keep their
  identities. Local relief, woods, farmland, landmarks, roads, ferries and
  bridges make the province useful for planning journeys.
- **Towns:** streets define blocks and building parcels. Markets, workshops,
  homes, gardens, harbors and citadels have different uses, roof colors and
  density. Coastal towns have an editable inlet and working docks. Terrain,
  paving, settlement size and ward names remain editable.
- **Buildings and dungeons:** building-purpose layouts include manors and
  workshops, connected circulation and accessible furnishing. Generated
  dungeon floors have connected areas, entrance/goal positions and paired
  stairs across levels.
- **Editing and print:** compare regeneration before Apply; Keep current map
  cancels it. Undo/redo covers map edits and groups a brush gesture into one
  step. Temporary layer switches simplify editing. PNG export includes the
  selected dungeon floor, supports up to 4× resolution and offers cancellation.
  Print treatments, legends and a configurable distance scale are available.

**Existing maps keep their original generation.** Choose **1.8 · improved
generation** to preview an upgrade. This can change generated geography and
site identities; the preview warns about affected links and edits. Custom
sites and overlays are retained, and linked entries are never deleted by
regeneration. Undo is local to the open map editor, not a replacement for a
world backup.

Linked regions are still frozen snapshots. **Refresh terrain from world**
previews a new snapshot using the saved window. New 1.8 crops carry the more
precise coastline and territory data; refresh an older crop from an upgraded
world to obtain them. Painting a region can deliberately change its shore.

## Handout workshop

Five templates start an ordinary Handout entry: **old book / journal, letter,
scroll, item card, and notice / wanted poster**. Writing remains in normal
text, heading and quote blocks. Presentation settings hold formatting and
references to block IDs, so backups, history and recovery retain the content.

The workshop offers A4, US Letter and two card sizes; local illustrations and
letter seals; cover pages, decorative initials, borders, paper and typography;
and selected fields or text from linked campaign entries. The printed title
can differ from the entry's wiki name.

Preview starts with the **player edition**. Hidden blocks and hidden, deleted
or secretly related source entries are removed before pagination and image
loading. Every GM output page carries a GM banner, including continuation
pages. Player and GM exports use the same layout as their respective previews.

Export a selectable-text PDF or a ZIP of page PNGs at 150 or 300 DPI. Arrange
multiple handouts into an ordered packet. Item cards can share printable A4
or US Letter sheets with crop marks; long cards continue onto additional
cards. Ink-saving output uses white paper. Missing images and unsupported
characters produce a warning rather than silently corrupting the document.

DejaVu serif and sans fonts are bundled locally under their included license.
Latin, Greek and Cyrillic text have been checked in preview and extracted PDF
text. Complex-script shaping is limited; unsupported glyphs appear as a
visible square with a warning. Images must be local assets in the same world.
Use a backup **with assets** to transfer them. New backups record their source
world ID, allowing image URLs to be rebased when restored into another world.

## Try the examples

The sample world includes **Atlas of the Lantern Seas**, its linked province
and inherited capital, and five handouts about the lighthouse keeper and a
brass key. These include original local artwork and a secret GM annotation.
The original sample maps are retained for comparison. Existing worlds are
not populated with new examples during an upgrade.

## Distribution and verification

Download **MundusMaker-1.8.0.zip**. This is one universal archive, with the
familiar Windows `.bat`, Linux `.sh` and Mac `.command` launchers. It includes
Windows x64, Linux x64/ARM64 and Mac Intel/Apple silicon Node v24.20.0 runtimes.
The self-contained **MundusMaker.app** provides normal Mac startup without
Terminal. Unsigned tester builds still require the OS's one-time approval;
see README-FIRST.html. Agent instructions, development fixtures and private
worlds are excluded from the archive.

Validation covers deterministic generation, coastline and territory transfer,
river drainage, land routes/ferries, building access, dungeon stair pairs,
editing history, handout privacy/pagination, save failures and transactional
restore. All 17 legacy PNG fixtures retain their original hashes. Browser
checks exercise regeneration, exports, local assets and offline operation.
PDF pages are rendered for visual inspection as well as text extraction.

Performance measurements are from a Windows development machine running
headless Edge: representative generation plus drawing took roughly 0.3–0.6 s
for a new world, 0.15–0.2 s for a region, and 0.05–0.16 s for a town at normal
preview resolution. Print rendering takes longer. These are observations,
not promises for other hardware.

Native macOS and Linux launch behavior and ordinary-laptop performance still
need testing on those systems. Archive integrity, executable permissions,
runtime architectures and Windows startup are checked on the build machine.
Handouts use bundled fonts; map label placement uses the browser's available
serif font and can vary slightly between operating systems.

Character creation, D&D advancement, printable system sheets, categories and
ready-written DM Screen references from 1.7.0 remain available. Automatic
encounter placement and an expanded keyed-room authoring workflow are not
part of this release.
